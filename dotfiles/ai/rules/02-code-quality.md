# Code Quality & Standards

- **Maintain Documentation Integrity**: Preserve existing comments and docstrings unless explicit changes are requested.
- **API Contracts**: Keep function signatures and component props consistent across all invocation sites.
- **Formatting & Style**: Follow PEP 8 for Python, standard formatting for TypeScript/JavaScript, and clean modular structure.
- **Minimal Dependencies**: Use built-in standard library tools or existing codebase utilities before introducing new third-party packages.
